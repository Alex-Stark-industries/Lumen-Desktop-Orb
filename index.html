Instant, on purpose

Every command is a small fixed routine — not a model deciding what to do.

⚡

No waiting

No language model means no "thinking" delay — every quick command answers the moment you click it.

🎙️

A real voice

Replies are spoken with a proper on-device neural voice, downloaded once and then fully offline.

🖱️

One menu, everything

Right-click the orb for a clean custom menu. No windows to manage, no settings screens to dig through.

🌦️

Weather & web search

The few commands that need a detail just ask for it inline — type a city, a search, or an app name.

🪶

Small and quiet

No multi-gigabyte model, no background service eating your RAM. It only ever downloads the voice itself.

🔒

Private by default

No accounts, no telemetry, no analytics. The only network use is the voice download and the two commands that are explicitly about the outside world.

Get started in a minute

No dependencies to install first — unlike bigger AI assistants.

1

Download the installer from the latest release.

2

Run it. No administrator rights needed — it installs just for your account. Windows SmartScreen may warn you since the installer isn't code-signed; click More info → Run anyway.

3

Right-click the orb that appears in the bottom-right of your screen, and try Time — that's the whole interaction model.
